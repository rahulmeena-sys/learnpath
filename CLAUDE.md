# LearnPath

**At the start of every session, read these files in order:**

1. [context/AGENT.md](context/AGENT.md) — working style, engineering principles, how to collaborate
2. [context/REPO.md](context/REPO.md) — repo structure, tech stack, environment, key commands
3. [context/PRODUCT.md](context/PRODUCT.md) — product vision, MVP scope, what we're building
4. [context/TASKS.md](context/TASKS.md) — current active tasks and their status

Update `context/TASKS.md` whenever a task changes state. All product and architecture decisions live in `context/PRODUCT.md`. Do not create new MD files outside of `context/` without asking first.
